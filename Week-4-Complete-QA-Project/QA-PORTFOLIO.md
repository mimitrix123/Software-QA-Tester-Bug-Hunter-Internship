# QA Engineering Portfolio — Week 4 Capstone

## Project
**End-to-End QA of SauceDemo / Swag Labs**

## Role
QA Tester / Automation Tester

## What I delivered
- Risk-based QA test strategy
- Detailed test plan
- 60 functional/manual test cases
- 15 critical Selenium UI automation scenarios using Python, pytest, and Selenium WebDriver
- Postman collection covering 5 REST API scenarios with assertions
- Apache JMeter load-test plan configured for 100 concurrent users
- Execution and evidence framework

## Coverage
Authentication → inventory → product details → sorting → cart → checkout → order confirmation → navigation → session behavior.

## Automation highlights
The Selenium suite covers both positive and negative authentication, inventory verification, sorting, cart operations, checkout validation, successful order completion, and logout.

## API highlights
The Postman collection covers GET collection, GET resource, POST, PUT, and DELETE with status and payload assertions.

## Performance highlights
The JMeter plan is configured for 100 virtual users with a 100-second ramp-up and 120-second duration. It is designed as a controlled baseline and should only be executed against an authorized environment.

## Professional QA practices demonstrated
- Requirement-to-test traceability
- Risk-based prioritization
- Repeatable automation
- API contract assertions
- Performance-test planning
- Evidence-based reporting
- Honest separation of planned versus executed results
