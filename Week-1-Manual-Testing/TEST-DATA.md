# Test Data

Use non-sensitive test data only. Never commit real passwords, tokens, personal information, or production credentials.

| Data | Example |
|---|---|
| Valid username | Use the credential published by the current OrangeHRM demo |
| Valid password | Use the credential published by the current OrangeHRM demo |
| Invalid username | `invalid_test_user_999` |
| Invalid password | `InvalidPassword!999` |
| Nonexistent employee | `ZZZ No Such Employee` |
| Nonexistent username | `no_such_user_999` |
| Search keyword | `Admin` |

## Credential handling
If the demo publishes temporary credentials on its login page or official documentation, use those credentials for the live run and do not store the password in this repository.
